# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [SemVer](https://semver.org/lang/ru/).

## [1.1.0] - 2026-11-21

### Добавлено
- **Летопись концовок**: открытые исходы сохраняются между запусками в `etheria-progress.cfg`, для закрытых показываются намёки.
- Экран итогов: номер исхода, отметка о новой записи в Летописи.
- Экран «Как играть» с правилами, ценой времени и подсказками по бою.
- Настройка скорости текста (мгновенно, быстро, обычно, медленно), запоминается между запусками.
- Главное меню показывает героя из сохранения и число открытых концовок.
- Параметры запуска `--instant`, `--no-fx`, `--help`.
- Резервный режим без PowerShell: игра проходима без анимаций.
- Динамические заметки в статусе: подсказки зависят от прогресса.
- Режим автотестов `ETHERIA_TEST=1`, `tests/Test-Game.ps1` и CI в GitHub Actions.
- `tools/Render-Media.ps1`: генерация скриншотов и анимации боя из настоящего вывода игры.

### Изменено
- Сохранение пишется рядом с игрой, а не в текущую папку консоли.
- Отдых у фонтана при полном здоровье больше не отнимает час.
- Ошибка записи сохранения показывается игроку.
- README переписан: скриншоты, механики, схема устройства, тесты, английская версия.

### Исправлено
- Повреждённое или отредактированное сохранение больше не ломает игру: значения проверяются и приводятся к допустимым.
- Сбой `choice` (код 255) больше не выбрасывает в случайный пункт меню.

## [1.0.0] - 2026-11-16

### Добавлено
- Первая версия: три класса, город-хаб, три задания, пошаговые бои с ASCII-анимацией, восемь загадок, восемь концовок, сохранение.
